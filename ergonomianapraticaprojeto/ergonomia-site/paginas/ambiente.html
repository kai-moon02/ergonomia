Condições ambientais de trabalho

O ambiente é tudo o que cerca a tarefa: luz, barulho, calor e ar. A NR-17 trata dessas condições de conforto no item 17.8 (BRASIL, 2021).

Fatores ambientais

  • Iluminação: deve ser adequada à tarefa e evitar ofuscamento, reflexos, sombras e contrastes excessivos (17.8.1 e 17.8.2). Os níveis mínimos seguem a NHO 11 da Fundacentro (17.8.3); em escritórios, a referência usada é 500 lux (CEFET/RJ, [s. d.]).
  • Ruído: onde há atenção constante, é preciso controlar o ruído. Vale o valor da norma técnica oficial do ambiente ou, nos demais casos, até 65 dB(A) (17.8.4.1).
  • Temperatura: faixa de 18 a 25 °C para ambientes climatizados (17.8.4.2).
  • Ventilação: evitar correntes de ar direto sobre as pessoas (17.8.4.2.1).

Atenção: valores como 20 a 23 °C, umidade mínima de 40% e vento até 0,75 m/s vinham da NR-17 de 1990, substituída pela redação de 2021. Muitos materiais da internet ainda os citam.

Normas e referências

  • NR-17, item 17.8: condições de conforto no ambiente de trabalho.
  • NHO 11 (Fundacentro): avaliação dos níveis de iluminamento em ambientes internos (FUNDACENTRO, 2018).
  • ABNT NBR 10152: referência técnica para níveis de pressão sonora em ambientes internos.
  • ABNT NBR ISO/CIE 8995-1: iluminação de ambientes de trabalho.

Avaliação ambiental prática

Meça o local com luxímetro, decibelímetro e termômetro (aplicativos de celular servem só como estimativa) e digite os valores.

Meu ambiente está adequado?

Ferramenta didática. Ela compara os valores com referências da NR-17 e não substitui a avaliação de um profissional habilitado.

Algoritmo deste item

ProblemaO ambiente de trabalho está dentro das referências de conforto?
EntradasIluminação (lux), ruído (dB(A)), temperatura (°C) e presença de vento direto (sim/não).
SaídasLista de fatores adequados e fatores a ajustar.

Passos

  1. Ler os quatro valores digitados.
  2. Comparar cada valor com a sua referência.
  3. Marcar o fator como “adequado” ou “ajustar”.
  4. Mostrar o resultado de cada fator e o total.

Esqueleto em JavaScript

function avaliarAmbiente(lux, ruido, temp, ventoDireto) {
  var problemas = [];
  if (lux < 500) { problemas.push('iluminação'); }
  if (ruido > 65) { problemas.push('ruído'); }
  if (temp < 18 || temp > 25) { problemas.push('temperatura'); }
  if (ventoDireto) { problemas.push('ventilação'); }
  return problemas; // lista vazia = ambiente adequado
}
